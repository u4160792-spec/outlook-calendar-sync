Privacy Policy

How the personal calendar synchronization utility processes and protects data.

Effective date: October 20, 2026

Overview

Outlook Calendar Sync is a personal-use Windows utility that transfers events from an authorized Microsoft Outlook calendar to a designated Google Calendar.

Information processed

The utility may process event titles, start and end times, dates, locations, and optionally event descriptions. It may read existing Google Calendar events to identify previously synchronized entries and prevent unnecessary duplicate creation.

Purpose and use

Information is used to perform user-authorized calendar synchronization. The application is not used for advertising, marketing, or profiling.

Google API access

The utility requests the Google Calendar permission necessary to read and manage events on calendars owned by the authorized Google account. Its use and transfer of information obtained through Google APIs will adhere to the Google API Services User Data Policy, including applicable Limited Use requirements.

Storage and sharing

Google OAuth tokens are stored locally using Windows Data Protection API encryption. Local event previews may be saved to the Windows computer. Event information is transmitted to Google Calendar via Google's API as required for the requested synchronization. The utility does not maintain a separate hosted calendar database. Calendar data is not sold or shared with advertisers.

Retention and user control

Users may stop the scheduled task, remove locally saved previews and authorization data, and revoke Google access through their Google Account permissions. Calendar events already synchronized to Google Calendar remain in that calendar unless removed by the user or an authorized synchronization action.

Organizational information

Users are responsible for ensuring that syncing workplace or third-party calendar content complies with their organization's data security policies.

Contact

For privacy inquiries, use the developer support email displayed in the application's Google OAuth consent screen.
