Calendar synchronization, simplified

A personal Windows utility for one-way synchronization from Outlook to a designated Google Calendar.

Personal use · Windows desktop

What this tool does

Outlook Calendar Sync reads calendar events from an authorized Microsoft Outlook calendar and synchronizes them to a Google Calendar selected by the account owner. It does not modify the source Outlook calendar.

Scheduled synchronizationRun on demand or through an existing Windows scheduled task.
Google OAuth 2.0Access Google Calendar only after the account owner authorizes it.
Locally protected tokensOAuth tokens are encrypted on the Windows computer using DPAPI.

Data and permissions

The utility may process event titles, dates, times, locations, and, if enabled, event descriptions. It uses the Google Calendar API to manage events on a user-owned calendar. No independent web server is used to collect calendar event data.

See the Privacy Policy and Terms of Service for further details.

Availability

This utility is intended for the developer's own use and is not offered as a public commercial service. Users must ensure they have permission to synchronize any work or organization calendar data.
